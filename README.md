## 🛠️ Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **3D Graphics**: Three.js, Custom GLSL Shaders (Perlin/Simplex Noise displacement)
- **Styling**: Tailwind CSS v4, Layered Glassmorphism System
- **Intelligence**: Google Gemini 3.1 Flash Live API (`gemini-3.1-flash-lite`)
- **Speech**: Web Speech API (STT & TTS)
- **Icons & FX**: Lucide React, Canvas Confetti

## 🚀 Quick Start (Local Setup)

```bash
# 1. Clone the repository
git clone https://github.com/chinmay72049-png/chinmay-portfolio.git

# 2. Enter project directory
cd chinmay-portfolio

# 3. Install dependencies
npm install

# 4. (Optional) Set up environment variables
cp .env.example .env

# 5. Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

## 🌐 Deployment

### Option A: GitHub Pages (Free Automatic Deployment)
This repository includes a pre-configured GitHub Actions workflow at `.github/workflows/deploy.yml`.
1. Go to your repository settings on GitHub: **Settings > Pages**.
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. Push to `main` and your portfolio will be automatically live at:
   `https://chinmay72049-png.github.io/chinmay-portfolio/`

### Option B: Vercel (1-Click Hosting)
1. Import `chinmay-portfolio` into [Vercel](https://vercel.com).
2. Framework Preset: **Vite**.
3. Click **Deploy**.
